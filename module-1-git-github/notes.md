## Key vocabulary (in your own words)

- repository: It stores all your project files, folders and the complete timeline of every change ever made to them
- commit: commit acts as a checkpoint with its own unique ID and a short message describing what changes were made
- branch: It lets you work on new features or bug fixes in isolation without messing up the working version of the project
- push / pull: Uploading your local commits / Downloading the latest commits from the remote server and combining them into your local workspace
- pull request: request to merge your branch's changes into another branch
- merge conflict: A merge conflict happens when Git gets confused because two branches changed the exact same line of code in different ways
